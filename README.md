### [RTLive - Футбольная платформа](https://github.com/Cyber-bober/Fullstack-website)
**Современная платформа для управления футбольными командами**

Современная платформа для управления футбольными командами с трансляциями и статистикой.

**Технологии:** Next.js 14, TypeScript, PostgreSQL, Prisma, Docker, Tailwind CSS

**Возможности:**
- Управление командами и составами
- Расчёт рейтингов
- Прямые трансляции матчей (VK Video)
- Чат и система поддержки
